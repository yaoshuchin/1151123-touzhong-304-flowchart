> 成果體驗網址：[https://yaoshuchin.github.io/1151123-touzhong-304-flowchart/](https://yaoshuchin.github.io/1151123-touzhong-304-flowchart/)

## 📌 專案簡介

本專案收錄並精確數位化南投縣立南投國中 115學年度 3年4班（投中304）全體同學所繪製之 17 份「AI旅程照片生成器」流程圖手稿。根據學校官方學生名冊核對座號與姓名，並依教育部個人資料保護規範將**學生姓名第二字以「O」進行去識別化替代**（如：姚O城、鄧O康、林O羽、許O崴、羅O鈞、謝O倢、王O億、林O妮、王O茹、王O等）。

更具突破性的是，本系統將全班**每一位同學的手寫流程圖手稿真正實作為 17 個獨立運行之專屬程式引擎**，每套程式皆完整還原該同學所構想的步數（5步/6步/7步）、專屬選項參數、專屬排版主題、以及專屬 HTML5 Canvas 海報合成！

---

## 🚀 系統三大核心功能

### 1. 🗂️ 學生手稿分類互動檢索庫
- **全班 17 份原稿**：完整收錄每位同學之手繪流程圖，經專業旋轉導正呈現。
- **個資保護與名冊校準**：嚴格依據 115 學年度南投國中學生名冊修正姓名，並統一以「O」遮罩第二字保護學生隱私。
- **高解析 Modal 檢視**：點選任一手稿卡片即可放大檢視手繪原圖、逐字文字辨識對照、步驟分解與創意特點。
- **一鍵啟動獨立程式**：點擊卡片上的「🎮 執行專屬獨立程式」即可一鍵切換至該同學的專屬互動程式！

### 2. 🎮 全班 17 份學生獨立程式工作台
使用者可隨時透過頂部「選擇要運行的學生專屬程式」下拉選單切換，體驗每位同學截然不同的創意心血：
- **🎖️ 14號 姚O城（國防裝備與軍事標語風格生成器，6步）**：
  - 軍事風格濾鏡、少尉/上尉/少校/特戰軍階自選、戰術鋼盔/防彈背心/夜視鏡裝備搭配、前線基地/航母/雷達站背景、同島一命國防精神標語、特戰檔案卡合成輸出。
- **🏮 15號 許O崴（節慶氛圍與形狀裁切相片生成器，6步）**：
  - 春節/中秋/端午/聖誕/元宵五大佳節、方形/圓形/心型/拍立得/五角星形等幾何形狀 Canvas 裁切遮罩、生活場景、節慶祝賀卡輸出。
- **⚡ 13號 林O羽（遊戲電競對話情節與精準標語生成器，5步）**：
  - 硝煙戰場/電競球場樣式、自選或自編角色經典台詞對白框、10~15字金句標語、電競 HUD 邊框遊戲封面卡輸出。
- **👰 17號 羅O鈞（跨國浪漫婚紗照生成與前後對比系統，5步）**：
  - 唯美婚紗風格、五大跨國旅拍勝地、五大浪漫背景、以及獨家內建【原圖 vs 婚紗合成 Before/After 前後互動滑桿對比檢視】！
- **🏀 18號 鄧O康 & 20號 王O（NBA 超級巨星同框與典藏球員卡，6步）**：
  - 第一步改為跟 NBA 球員合照、收錄 14 位跨世代 NBA 巨星（柯瑞、詹姆斯、喬丹、布萊恩、東契奇、文班亞馬等）、主場球館、燙金立體球員徽章、球星背號、官方球員典藏卡輸出。
- **🌊 16號 蔡O緯（海陸空全維度冒險旅程生成器，6步）**：
  - 大海深藍/走遍陸地/天上飛行三維空間、台北101/台南安平/花東/阿里山全台景致、潛水鏡/登山杖/飛行傘極限裝備、探險隊長造型、海陸空座標羅盤圖卡。
- **🏛️ 06號 謝O倢（全功能七步驟旅程寫真系統，7步）**：
  - 皮克斯 3D 風格、古蹟考古探秘任務、獨立標語生成工序、全尺寸旅程寫真卡。
- **📹 19號 鍾O洧（Webcam 即時實景串流風格網頁，6步）**：
  - 聚焦網路攝影機即時實景預覽串接、六步驟引導、即時濾鏡色彩對比調校。
- **🏆 11號 王O億 / 03號 翁O涵 / 08號 藍O媗 / 09號 黃O芳 / 10號 胡O紜 / 02號 林O妮 / 01號 王O茹 / 全案整合代表**：
  - 10風格 x 10地點 x 5情境 x 6背景旗艦引擎、Stepper 驗證防呆、UI 快速選取、四元維度、智慧文案生成與一鍵下載 PNG。

### 3. 📖 四大維度功能矩陣與 Word 彙編
- 提供 10 風格、10 地點、5 情境、6 背景、14 NBA巨星之完整圖文字典。
- 專案內附專業編排之 Word 報告：`1151123投中304流程圖.docx`（內含封面、章節規劃、去識別化學生姓名、高解析原稿嵌圖與全班共識對照總表）。
